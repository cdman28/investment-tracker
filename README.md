# 📊 Investment Tracker

## 프로젝트 개요

**Investment Tracker**는 PC와 모바일에서 모두 사용할 수 있는 개인용 투자 기록 웹 애플리케이션입니다. 복잡한 개별 종목 관리 대신, 증권사별 계좌의 **전체 평가금액**을 주기적으로 기록하여 투자 성과를 직관적으로 추적하고 분석할 수 있도록 돕습니다.

모든 데이터는 사용자의 **GitHub Gist**에 안전하게 저장되므로, 별도의 서버나 데이터베이스 없이 개인 GitHub 계정만으로 모든 기능을 사용할 수 있습니다.

## ✨ 주요 기능

- **간편한 기록**: 날짜와 현재 계좌의 총 평가금액만 입력하면 기록 끝.
- **정확한 수익률 계산**: 입금/출금 기록을 바탕으로 원금을 정확히 추적하여 단순 산술 방식으로 수익률을 계산합니다. 연환산 수익률은 누적 수익률을 투자 기간으로 정규화하여 계산합니다.
- **다중 계좌 관리**: 여러 증권사 계좌를 각각의 탭으로 분리하여 관리하고, 전체 자산 현황을 한눈에 파악할 수 있습니다.
- **성과 시각화**:
  - **라인 차트**: 기간별(1개월, 3개월, 1년, 전체) 자산 추이를 시각적으로 분석합니다.
  - **파이 차트**: 전체 자산에서 각 증권사가 차지하는 비중을 확인합니다.
  - **목표 수익률 라인**: 증권사별로 설정한 목표 수익률을 차트 상에 표시하여 성과 달성 여부를 쉽게 파악할 수 있습니다.
- **핵심 지표(KPI) 대시보드**: 총 투자원금, 현재 평가금액, 총 손익, 수익률 등 핵심 지표를 실시간으로 제공합니다.
- **데이터 관리**: 모든 기록을 CSV 또는 JSON 파일로 내보내거나, JSON 파일로 복원할 수 있습니다.
- **개인화**:
  - 증권사별로 고유 색상과 목표 수익률을 지정할 수 있습니다.
  - 다크 모드와 라이트 모드를 지원합니다.

## 🛠️ 기술 스택

- **Frontend**: Vanilla JavaScript (ES2022+), HTML5, CSS3 (Flexbox/Grid, CSS Variables)
- **차트**: Chart.js
- **데이터 저장소**: GitHub Gist (서버리스)
- **인증**: GitHub Personal Access Token (PAT)

## 🚀 시작하기

1.  **GitHub Gist 생성**:
    - [gist.github.com](https://gist.github.com/)에 접속하여 새 Gist를 생성합니다.
    - 파일명은 `investment-tracker-data.json`, 내용은 `{}` 로 입력합니다.
    - **"Create secret gist"** 버튼을 눌러 비공개 Gist로 생성합니다.
    - 생성된 Gist의 URL에서 32자리 영숫자로 된 **Gist ID**를 복사합니다.

2.  **Personal Access Token (PAT) 발급**:
    - GitHub 설정의 [Developer settings > Personal access tokens](https://github.com/settings/tokens)로 이동합니다.
    - **"Generate new token"**을 클릭하고, `gist` 스코프에만 체크한 후 토큰을 발급받습니다.
    - 발급된 토큰(ghp_...)을 안전한 곳에 복사해 둡니다. (이 페이지를 벗어나면 다시 볼 수 없습니다.)

3.  **앱 실행 및 연결**:
    - Investment Tracker 웹앱에 접속합니다.
    - 초기 설정 화면에서 위에서 발급받은 **PAT**와 **Gist ID**를 입력합니다.
    - **[연결 확인]** 버튼을 눌러 정상적으로 연결되는지 확인한 후 **[시작하기]** 버튼을 누르면 바로 사용할 수 있습니다.
