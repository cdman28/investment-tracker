Investment Tracker

GitHub Gist를 저장소로 사용합니다.
Personal Access Token(PAT)과 Gist ID를 입력하면 바로 시작할 수 있습니다.

처음이신가요? 간단 설정 안내
1 gist.github.com에서 새 Gist 생성 → 파일명: investment-tracker-data.json, 내용: {} → Create secret gist
2 생성된 Gist URL에서 ID 복사 (예: gist.github.com/user/abc123...)
3 GitHub Settings → Developer Settings → Personal Access Tokens → gist 스코프 체크 후 토큰 발급
